# Agent instructions

## Repository map

This is `react-use-is-online`, a React hook library, not a web application.

- `src/index.ts`: `useIsOnline`, its return shape, and public types.
- `src/getConnection.ts`: native/prefixed Network Information access and request-timing fallback.
- `src/index.test.tsx`: browser behavior with Jest and React Testing Library.
- `src/ssr.test.tsx`: server rendering in Jest's Node environment.
- `lib/`: committed JavaScript and declarations generated by TypeScript; edit source first.
- `package.json`: package entry points, published file allowlist, peer dependencies, and scripts.

## Working conventions

Inspect the implementation and relevant tests before changing behavior. Preserve unrelated work.
The current peer range starts at React 16.8, while the test environment uses React 18; do not introduce newer React runtime APIs without addressing compatibility explicitly.
Keep browser online status distinct from internet/backend reachability. Connection estimates are approximate and must not gate connectivity subscriptions.
Preserve SSR safety and listener cleanup. Document deliberate public behavior changes in the README.

Use `npm ci` for the committed `package-lock.json` when dependencies are needed. Yarn configuration also exists; avoid incidental package-manager or lockfile migrations.
For code changes, run `npm test -- --runInBand` and `npm run build`, then inspect generated diffs. The build currently emits test artifacts into `lib/` as well.
The legacy lint script invokes TSLint, which is not directly declared in devDependencies; report tooling failures rather than silently replacing the linter.
Documentation-only changes need link/content and whitespace checks, not a dependency installation.
Report the checks actually run and any compatibility or verification limits. Publishing and version changes require task-specific authorization.
